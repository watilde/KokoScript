# KokoScript

日本語で書けるJavaScriptのサブセット言語

## 概要

KokoScriptは、「もし日本人がJavaScriptを作ったら」という世界観で設計された、日本語ベースのプログラミング言語です。
句読点（、と。）を主要な区切り文字として活用し、スペースに依存しない自然な日本語の文章のようにコードを書くことができます。
内部的にはJavaScriptにトランスパイルされます。

## 特徴

- 🇯🇵 日本語のキーワードを使用
- 📝 句読点（、。）を主要な区切り文字として活用
- 🚀 スペース不要 - 「名前は値」や「繰り返す」のような連続したキーワードも正しく認識
- 🔄 JavaScriptへの自動トランスパイル
- 💡 シンプルで学びやすい構文
- 🌸 日本語の自然な語順を尊重

## 構文例

```
変数、名前は「田中」。
変数、年齢は25。

もし、年齢が20より大きいならば、
  「成人です」を表示。
そうでなければ、
  「未成年です」を表示。
終わり。

3回、繰り返す、
  「こんにちは」を表示。
終わり。

関数、挨拶するは、名前で、
  「こんにちは、」と名前と「さん」を表示。
終わり。

挨拶するに「太郎」を渡す。
```

## 構文詳細

### 変数宣言
```kokoscript
変数、変数名は値。
```

### 表示
```kokoscript
「文字列」を表示。
「こんにちは、」と名前と「さん」を表示。
```

### 条件分岐
```kokoscript
もし、条件ならば、
  処理。
そうでなければ、
  処理。
終わり。
```

比較演算子：
- `より大きい` (>)
- `より小さい` (<)
- `以上` (>=)
- `以下` (<=)
- `等しい` (==)

### 繰り返し
```kokoscript
回数回、繰り返す、
  処理。
終わり。
```

### 関数
```kokoscript
# 定義
関数、関数名は、引数で、
  処理。
終わり。

# 呼び出し
関数名に引数を渡す。
```

### コメント
```kokoscript
# これはコメントです
```

### 句読点の使い方

KokoScriptでは、日本語の句読点を**主要な区切り文字**として活用しています：

- **読点（、）**: キーワードの直後、句の区切りに使用（**必須**）
- **句点（。）**: 文の終わりに使用（**必須**）

句読点を使用することで：
1. スペースなしでキーワードと識別子を区別できる（例：「名前は」→ 「名前」+ 「は」）
2. 複合キーワードを正しく認識できる（例：「そうでなければ」を一つのキーワードとして認識）
3. 日本語の自然な文章のように読みやすいコードになる

### ✨ スペース不要の設計

KokoScriptは句読点ベースの設計により、スペースなしで書けます：

✅ 正しく動作する例:
```kokoscript
変数、名前は「太郎」。
「こんにちは、」と名前と「さん」を表示。
3回、繰り返す、
  「カウント中」を表示。
終わり。
もし、年齢が20より大きいならば、
  「成人」を表示。
そうでなければ、
  「未成年」を表示。
終わり。
```

レキサーは以下のルールで自動的にトークン化します：
1. 句読点（、。）で区切る
2. 最長マッチ優先で複合キーワードを認識（例：「そうでなければ」は「そう」+「で」+「なければ」ではなく一つのキーワード）
3. 数字や文字列リテラルで自動的に区切る

スペースは読みやすさのために入れることもできますが、必須ではありません。
