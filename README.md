# KokoScript

日本語で書けるJavaScriptのサブセット言語

## 概要

KokoScriptは、日本語の自然言語のように見える構文でプログラミングができる言語です。
句読点を活用し、より自然な日本語の文章のようにコードを書くことができます。
内部的にはJavaScriptにトランスパイルされます。

## 特徴

- 日本語のキーワードを使用
- 句読点（、。）を活用した自然な構文
- JavaScriptへの変換が可能
- シンプルで学びやすい

## 構文例

```
変数、名前は「田中」。
変数、年齢は25。

もし、年齢が20より大きいならば、
  「成人です」と表示。
そうでなければ、
  「未成年です」と表示。
終わり。

3回、繰り返す、
  「こんにちは」と表示。
終わり。

関数、挨拶するは、名前で、
  「こんにちは、」と名前と「さん」を表示。
終わり。

挨拶するに「太郎」を渡す。
```

## インストール

```bash
npm install
```

## 使い方

```bash
# ファイルを実行
node kokoscript.js example.koko

# インタラクティブモード
node repl.js
```

## 構文詳細

### 変数宣言
```kokoscript
変数、変数名は値。
```

### 表示
```kokoscript
「文字列」と表示。
「こんにちは、」と名前と「さん」と表示。
```

### 条件分岐
```kokoscript
もし、条件ならば、
  処理。
そうでなければ、
  処理。
終わり。
```

比較演算子：
- `より大きい` (>)
- `より小さい` (<)
- `以上` (>=)
- `以下` (<=)
- `等しい` (==)

### 繰り返し
```kokoscript
回数回、繰り返す、
  処理。
終わり。
```

### 関数
```kokoscript
# 定義
関数、関数名は、引数で、
  処理。
終わり。

# 呼び出し
関数名に引数を渡す。
```

### コメント
```kokoscript
# これはコメントです
```

### 句読点の使い方

KokoScriptでは、日本語の句読点を活用して、より自然な構文を実現しています：

- **読点（、）**: 句の区切り、パラメータの区切りに使用（省略可能）
- **句点（。）**: 文の終わりに使用（省略可能）

読点と句点は省略可能ですが、使用することでより自然な日本語の文章のように見えます。
